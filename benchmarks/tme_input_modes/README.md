# Comparação futura de modos de entrada TME

Cada item real e consentido deve vincular a mesma resolução a uma captura em strokes, uma imagem de scan e uma transcrição de referência revisada. Registre IDs pseudônimos, versões de provider e opções, hashes das fontes e tempos de captura, reconhecimento e revisão.

Calcule CER, erros em símbolos críticos (sinais, frações e expoentes), número de revisões manuais e efeito das diferenças de transcrição sobre `AuditResult`. Compare por questão e por página; não agregue soluções matematicamente distintas como se fossem pares. Nenhum dado de benchmark foi criado nesta tarefa.
